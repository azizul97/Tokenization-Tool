This project is a Tokenization Tool that analyzes and classifies tokens from C/C++ programs. The tool identifies keywords, operators, special characters, functions, headers, and numeric literals from input code. It is built using Python and Tkinter for the GUI.

Features:
* Tokenizes C/C++ source code and categorizes tokens.
* GUI Interface built using Tkinter.
* Identifies Keywords, Operators, Headers, Functions, and Special Characters.
* Symbol Table Analysis (Upcoming Feature).
* Reset Button to clear inputs and results.

Installation & Setup:

🔹 Prerequisites

Ensure you have Python 3.x installed. Then, install dependencies:

pip install tkinter

🔹 Run the Project

python tokenizer.py
